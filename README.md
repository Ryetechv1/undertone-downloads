# Undertone 3.1 public installation guide

Share https://ryetechv1.github.io/undertone-downloads/ with iPhone and Android friends.

Undertone 3.1, build 6 is being prepared with the five recordings captured from the owner's assigned iPhone mix. Public app downloads remain inactive until the finalized packages are uploaded to a GitHub Release and release.json is marked ready.

This repository contains static guide files only. Application source remains in its existing private repository. App binaries and the shared starter recordings will be distributed through versioned GitHub Release assets, not through the Pages Git history.

See [IOS-INSTALL.md](IOS-INSTALL.md), [ANDROID-INSTALL.md](ANDROID-INSTALL.md), and [APP-GUIDE.md](APP-GUIDE.md).

## Target compatibility

The release targets **iPhone 14, iPhone 14 Plus, iPhone 14 Pro and iPhone 14 Pro Max**, along with other supported iPhones running **iOS 17 or later**. Install the same IPA on these models; a separate model-specific download is not needed.

Android 9 or later requires updated Android System WebView and/or Chrome. The upcoming starter release is not yet published.
